# Валютный журнал

Прототип для учета сделок с USD, CNY и валютными облигациями. Журнал показывает списание партий по FIFO, расчетную базу по валюте и формирует черновик 3‑НДФЛ.

Для первого знакомства выберите учебный сценарий и нажмите «Загрузить пример». Кнопка «Разбор» рядом с продажей показывает, как посчитан результат.

Сделки и настройки хранятся локально в браузере. Кнопка «Очистить журнал» удаляет сделки за все годы после подтверждения.

PDF за 2026 год использует бланк 2025 года и помечается как черновик. Перед подачей сверяйте расчеты с документами и используйте форму ФНС за нужный год.

## Локальный запуск и проверка

Откройте `index.html` в браузере. Все ресурсы находятся рядом с ним, отдельная сборка не требуется.

Для запуска автоматизированных проверок выполните из корня репозитория:

```sh
node tests/test-valuta.cjs
```
